【后端】
1. 新建路由文件 backend/app/routers/work_order_alerts.py
2. APIRouter prefix="/api/work-order-alerts", tags=["工单逾期预警"]（中文）
3. GET /api/work-order-alerts
   - summary="工单逾期预警列表"
   - description="查询已过计划结束日仍未完成的工单；工单逾期预警页数据来自本接口。"
   - 需登录 Depends(get_current_user)
   - Query: page(从1)、size、production_line(可选)、keyword(可选，匹配工单号/产品名)
   - 判定：end_date 不为空且 end_date < 今天，且 status 不在 completed/cancelled（若无 cancelled 则仅排除 completed）
   - 返回 { items:[{id,order_no,product_name,production_line,plan_quantity,actual_quantity,status,priority,assignee,end_date,overdue_days}], total, page, size }
   - overdue_days = (今天 - end_date).days
4. 在 backend/app/main.py include_router 注册该路由
5. 如项目有 openapi_zh.py，为该接口补中文 summary（可选但推荐）

【前端】
1. 新建 frontend/src/api/workOrderAlerts.js（参考 messages.js 的 authFetch）

   - 标题「工单逾期预警」
   - 筛选：产线、关键词；表格列：工单号、产品、产线、计划数、实际数、状态、优先级、负责人、计划结束、逾期天数
   - 逾期天数用红色强调；分页
   - Element Plus，风格对齐 WorkOrdersView / messages
